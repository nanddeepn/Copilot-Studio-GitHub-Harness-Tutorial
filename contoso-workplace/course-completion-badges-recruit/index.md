# Course complete: Continue your learning

<mission-meta />

You have worked through the Recruit path: prepared a test environment, designed and built an agent, connected knowledge and tools, added skills, created a workflow, and reviewed publishing and usage considerations.

## Optional badge request

If the Recruit NextGen badge program is open, follow its current validation process:

1. Visit the [Agent Academy repository](https://github.com/microsoft/agent-academy) and complete any repository-engagement requirement stated by the current badge form.
2. Use the current [Recruit NextGen badge form](https://aka.ms/agent-academy-recruit-nextgen/form), if available.
3. Follow the form's instructions for the issuing platform and account details. Use the same email address where the program requires it.

Program availability, eligibility, links, and issuance policies can change. Confirm the details in the current form rather than treating this lesson as a guarantee of a badge.

## Keep building safely

Before adapting the sample for real employees, replace test data and addresses, review permissions and organizational policies, verify the agent's sources, test failure paths, and agree on monitoring and ownership. A published agent is not automatically a production-ready service.

Congratulations on completing the learning path. Return to the [Recruit course overview](../index.md) to revisit a lesson or share the course with a teammate.
